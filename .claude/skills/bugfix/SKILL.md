---
name: bugfix
description: Исправление бага через воспроизведение — гипотеза, падающий тест, минимальный фикс, зелёная регрессия. Использовать для любого бага.
---

1. **Гипотеза.** Опиши причину со ссылкой на `файл:строка` и сценарий, при котором баг проявляется.
2. **Воспроизведение.** Напиши тест в `tests/`, который падает из-за бага. Запусти `npm test` и покажи падение.
   Если логику нельзя протестировать без рефакторинга (код внутри React-компонента) — сначала
   предложи человеку минимальное извлечение чистой функции; не делай его молча.
   Если тест невозможен — опиши ручной сценарий воспроизведения и явно отметь это ограничение.
3. **Фикс.** Минимальное изменение, устраняющее причину, а не симптом.
4. **Регрессия.** `npm run check` зелёный; тест из п.2 теперь проходит. Покажи вывод.
5. **Отчёт** — через скилл `/done`.

После двух неудачных попыток фикса остановись и предложи новую сессию или передать задачу человеку.

Описание бага: $ARGUMENTS
