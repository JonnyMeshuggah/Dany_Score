---

Сформулируй постановку и покажи её человеку **до** любых изменений файлов:

```
Цель: <что должно измениться для пользователя>
Сценарий: <шаги и ожидаемый результат>
Область: <файлы, которые можно менять>
Нельзя менять: <файлы/контракты/данные>
Риск: <низкий/средний/высокий> — <почему, по docs/agents/RISK.md>
Критерии приёмки: <проверяемые: тест, команда, сценарий на Preview>
Проверка: <какие команды докажут результат>
Размер diff: <ожидаемый>
Rollback: <для высокого риска — как откатить>
```

Если чего-то не хватает — спроси, не додумывай. Для среднего и высокого риска после согласования
постановки перейди в исследование и план (Plan Mode), реализацию начинай только после подтверждения плана.

Аргументы пользователя: $ARGUMENTS
