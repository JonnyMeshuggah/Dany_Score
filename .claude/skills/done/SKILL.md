---
name: done
description: Завершение задачи по Definition of Done — запуск проверок, отчёт с доказательствами, ревью свежим контекстом для среднего/высокого риска. Использовать прежде чем сказать, что задача готова.
---

1. Запусти `npm run check` и `git status` + `git diff --stat`. Если проверка красная — задача не готова:
   исправь или честно сообщи, что не прошло, с выводом.
2. Просмотри diff целиком: ограничен задачей? нет секретов, лишних зависимостей, отладочного кода?
3. Определи риск по `docs/agents/RISK.md`. Для среднего и высокого — запусти агента `reviewer`
   с описанием задачи и критериями приёмки. Покажи его вердикт; блокеры исправь или явно отклони с причиной.
4. Выдай отчёт в формате `.github/pull_request_template.md`: цель, риск, что изменено, команды и ключевой
   вывод, результат review, ограничения и непроверенное, rollback (для высокого риска).
5. Пройди чек-лист Definition of Done из `docs/agents/WORKFLOW.md` и отметь каждый пункт.

Не коммить и не пушь без просьбы человека.
