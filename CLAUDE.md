## Claude Code
- Риск средний/высокий → начни в Plan Mode; реализация только после подтверждения плана.
- Скиллы: `/task` — постановка, `/bugfix` — фикс через падающий тест, `/done` — доказательства и DoD.
- Review — агент `reviewer` (свежий контекст, другая модель); результат показать человеку.
- Параллельная работа — только через worktree (`--worktree` / EnterWorktree).
- Блокировку от хука `guard.mjs` не обходить другими командами — сообщить человеку.
